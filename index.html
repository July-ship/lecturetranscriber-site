LectureTranscriber

Запись и автоматическая расшифровка онлайн-лекций

О программе

LectureTranscriber - приложение для Windows, предназначенное для записи звука компьютера и преобразования речи в текст.

Программа помогает сохранять содержание лекций, вебинаров и онлайн-встреч в виде текстовых документов для последующего изучения.

Возможности

  • Запись звука, воспроизводимого на компьютере.
  • Локальная расшифровка с помощью Whisper.
  • Онлайн-расшифровка через AssemblyAI с разделением по спикерам.
  • Сохранение результатов в форматах TXT и DOCX.
  • Загрузка Word-документов на Google Диск с разрешения пользователя.

Работа с Google Диском

LectureTranscriber использует Google Drive API для сохранения созданных документов в Google Диске пользователя.

Приложение запрашивает разрешение на работу только с файлами Google Диска, созданными или открытыми через приложение.

Пользователь самостоятельно разрешает доступ через стандартное окно авторизации Google.

Конфиденциальность

При использовании онлайн-расшифровки аудиозаписи передаются сервису AssemblyAI для обработки. При локальной расшифровке Whisper обработка выполняется на компьютере пользователя.

Подробнее об обработке данных будет указано в политике конфиденциальности.
