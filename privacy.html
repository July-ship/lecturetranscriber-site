Политика конфиденциальности LectureTranscriber

Дата обновления: 15 ноября 2026 года

1. Общая информация

LectureTranscriber - приложение для Windows, предназначенное для записи звука компьютера, автоматической расшифровки речи и сохранения результатов в текстовых документах.

Настоящая политика описывает обработку данных при использовании приложения.

2. Запись и обработка аудио

Запись звука начинается по команде пользователя.

При выборе локальной расшифровки Whisper обработка аудио выполняется на компьютере пользователя.

При выборе AssemblyAI аудиозапись передается сервису AssemblyAI через интернет для преобразования речи в текст и разделения участников разговора.

Обработка данных сервисом AssemblyAI также регулируется политикой конфиденциальности этого сервиса.

3. Использование Google Диска

LectureTranscriber использует Google Drive API для загрузки созданных Word-документов в Google Диск пользователя.

Доступ предоставляется пользователем через стандартную авторизацию Google. Приложение использует разрешение drive.file, ограничивающее доступ файлами, созданными или открытыми через приложение.

Приложение не использует данные Google Диска для рекламы и не продает их третьим лицам.

Данные, полученные через Google API, используются для предоставления функций приложения в соответствии с Google API Services User Data Policy , включая требования Limited Use.

4. Хранение данных

Результаты расшифровки сохраняются на компьютере пользователя. При включенной загрузке документы также сохраняются в его Google Диске.

Данные авторизации Google и настройки приложения хранятся локально на компьютере пользователя.

5. Управление доступом и удаление данных

Пользователь может отозвать разрешение на доступ к Google Диску через настройки аккаунта Google .

Пользователь может самостоятельно удалять созданные документы из Google Диска и локального архива.

Для получения информации об удалении локальных данных приложения можно обратиться по адресу электронной почты, указанному ниже.

6. Сторонние сервисы

Приложение использует AssemblyAI для онлайн-расшифровки и Google Drive API для загрузки документов.

Использование этих сервисов регулируется их собственными условиями и политиками.

7. Изменения политики

Политика может обновляться при изменении функциональности приложения или способов обработки данных.

8. Контактная информация
